# 🏡 House Price Prediction Web Application

This project predicts the selling price of residential homes using Machine Learning.  
It is built with **Python**, trained using a **Random Forest Model**, and deployed as an interactive **web app** using **Streamlit**.

---

## 📌 Features
- Data cleaning and preprocessing
- Feature selection and model training
- Random Forest Regressor for prediction
- Real-time user input for house details
- Interactive Web UI using Streamlit

---

## 🧠 Model & Dataset
The dataset used is from the **Kaggle House Prices - Advanced Regression Techniques** competition.

### Input Features Used for Prediction:
| Feature | Meaning |
|--------|---------|
| GrLivArea | Above ground living area (sq ft) |
| OverallQual | Overall material & finish quality (1–10) |
| GarageCars | Number of cars the garage can hold |
| TotalBsmtSF | Basement area (sq ft) |

The model was trained using **Random Forest (500 trees)** for accuracy and consistency.
